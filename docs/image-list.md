# Image list

Every page currently shows real photos from `images/` (the 45 existing photos are reused; the build
makes resized WebP copies in `images/w/`). No page shows a broken or missing image: the build stops
if any referenced file is missing.

The photos below would replace generic hero photos on state and city pages that do not yet have a
photo of their own region. Generate each in Artistly, save it under the file name shown in `images/`,
then set `hero_img:` in that page's source (`_src/pages/...src.html`) to the new name and run
`python3 _src/build.py`. Nothing is broken while they are missing.

Size: 1920 x 1080 JPG (the build makes the WebP sizes). Style for every prompt: bright, clearly
visible, investor and real-estate scenes, no text, no logos, no recognizable faces.

The existing hero photos are 1536 x 640 or 1600 x 600. They display well, but on very wide screens a
1920 x 1080 source would be sharper. Lowest priority; same file names can be replaced in place.
